## 📦 Asset Architecture

* **Storage:** 100% self-hosted on personal GitHub repository (`bacharya02/workout-assets`).
* **Integrations:**
  * **Google Sheets:** Directly embedded via `=IMAGE(...)` formula with zero third-party dependency.
  * **Offline Web Guide:** Fully responsive local dashboard in `index.html`.

## 🏋️ Routine Overview
1. **🔵 Pull Day:** Upper body pulling biased towards lat width, rear delts, and core stability without lumbar shearing.
2. **🔴 Push Day:** Chest, shoulders, and tricep hypertrophy using converging and neutral grips to eliminate shoulder impingement.
3. **🟢 Leg Day:** 100% hip-socket safe quad, hamstring, and calf development (no axial squats, no deep hip pinching >90°).
4. **🧘 Daily Mobility & Stretching:** 
   * ☀️ Pre-Workout dynamic warmups tailored to each day's biomechanics.
   * 🌙 Post-Workout targeted tension releases.
   * ⭐ **Rest Day Master Flow:** 10-step full-body decompression sequence.
